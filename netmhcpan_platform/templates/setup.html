Why do I need to install this myself?

netMHCpan-4.2 is academic-licensed software from DTU Health Tech (Technical University of Denmark). Its license explicitly prohibits redistribution to third parties (not give the program to third parties). For that reason, TRIAD's Docker image ships without the netMHCpan-4.2 binary, data files, or license text — each user must request and download their own copy from DTU under their own license acceptance, then install it into the directory this platform expects.

1. Go to the official DTU download page, read and accept the netMHCpan-4.2 academic license, and download the Linux package (filename looks like netMHCpan-4.2.Linux.tar.gz).

Option A — Docker volume mount (recommended, no upload needed)

After downloading, extract it on the host and mount it into the container at NETMHC_HOME:

tar -xzvf netMHCpan-4.2.Linux.tar.gz
docker run -d --name triad_app -p 5001:5001 \
  -v "$(pwd)/netMHCpan-4.2:/opt/netMHCpan-4.2" \
  triad-platform:{{ platform_version }}

Or use the netmhc_data volume example already set up in docker-compose.yml. Refresh this page once it's mounted.

🖥️ Docker Desktop GUI Users — Host Port Setting (5001)

When running this image via Docker Desktop GUI, expand Optional settings → Ports before clicking Run, and enter 5001 into the Host port field (mapping to :5001/tcp):

⚠️ If you leave Host port blank, Docker Desktop assigns a random host port and http://localhost:5001 will fail to load.

Option B — Upload the package directly

If mounting a host volume isn't convenient, upload the tar.gz you just downloaded here — the system will extract, verify, and install it automatically.
